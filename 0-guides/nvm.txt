🟢 NVM (Node Version Manager) Quick Guide

🛠️ Install Curl: 
sudo apt install curl

📥 Install NVM: 
curl https://raw.githubusercontent.com/creationix/nvm/master/install.sh | bash


🌍 List Remote Versions (All available): 
nvm list-remote

🏠 List Local Versions (Already installed): 
nvm list

📍 Check Current Active Version: 
nvm current

📥 Install a Specific Version: 
nvm i v20.20.0

🔄 Switch to a Version: 
nvm use v20.20.0

📌 Set Permanent Default: 
nvm alias default 20.20.0
